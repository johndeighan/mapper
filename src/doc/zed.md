Zed Text Editor
===============

I'm using the new zed text editor

i = switch to input mode
Esc = switch to command mode

Ctrl-Shift-P = command pallet
Ctrl-, = settings
Ctrl-` = toggle terminal

Ctrl-TAB = switch current file (repeat to select)
:Ex Ctrl-o = open a new file

j = move down
h = move left
k = move up
l = move right
:w<Return> = write file
:wq<Return> = write file and quit
0 = move to start of line
$ = move to end of line
w = move to start of next word
b = move to start of previous word
1G = move to first line
<n>G = move to line n
G = move to last line
Ctrl-f = move forward one screen
Ctrl-b = move back one screen
u = undo your last action
i = insert text before cursor
I = insert text at start of line
a = insert text after cursor
A = insert text at end of line
o = add new line below current line
O = add new line above current line
x = delete single character under cursor
dd = delete entire current line
<n>dd = delete n lines
<n>x = delete n characters
yy = cut current line into buffer
<n>yy = cut n lines into buffer
p = paste lines from buffer after current line
/string = search forward for string
?string = search backward for string
n = move to next occurance of search string
N = move to previous occurance of search string
